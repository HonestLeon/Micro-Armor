# AI味体现在哪里？——AI写作的七个可识别特征

## 引言：什么是"AI味"

"AI味"不是语法错误，也很少是事实错误。它是一组稳定复现的**形式习惯**：文本看起来完整、专业、有条理，标题、编号、加粗、表格、Emoji 一应俱全，读完之后却很难说出具体信息。

它的成因并不神秘：

- **对齐训练**：模型被训练成有帮助、诚实、无害，于是习惯先划清边界、再发表意见；
- **语料迁移**：科普文章里"很多人以为……其实……"的纠正句式，被不加区分地搬到了所有场合；
- **使用惯性**：用户常要求"结构化""可直接使用"，清单、表格、编号因此成为默认输出；
- **阅读场景**：内容多在聊天窗口里被快速扫读，项目符号与 Markdown 格式因而更受青睐。

下面七个特征，是"AI味"最常见的落点。每一条都可以单独出现，也可以叠加出现——叠加越多，味道越浓。

## 一、先否定，再陈述

**表现**："不是……而是……""不只是……而是……"，先替读者树立一个误解，再负责纠正它。

> AI不是在替代你思考，也不只是帮你写 PPT，而是在重新定义"思考"本身。

**为什么**：一句话如果直接说出来，可能显得平淡；先否定一个并不存在的说法，再给出结论，语气立刻变得深刻。这种"负向排比"在纠正误解时是有效的，但被滥用后就成了固定的开场模板。

**识别方法**：删掉否定的那半句，剩下的信息有没有减少？如果没有，否定就只是修辞，不承载信息。

## 二、一句话也要做成表格或清单

**表现**：内容只有一句大白话，却被拆成三列表格、五个项目符号。

**为什么**：表格本来用于数据密集、关系复杂的场合。而在结构化输出的要求下，任何内容都可以被"布置成货架"——横向比较、纵向分层、每格一句，看起来像分析，实际只是排版。

**识别方法**（原文给出的判据很实用）：删除表格或列表后，信息有没有发生变化？如果完全没有，那这张表的作用不是传递信息，而是**呈现结构**。

据一项覆盖 16 组数据、9 种语言的人类与机器文本比较研究，机器文本更常使用项目符号与 Markdown 格式，原因正在于聊天窗口的快速扫读需求。

## 三、万物皆三：两点像列举，三点像模型

**表现**：任何话题都能拆成三个阶段、三个层次、三个 BOSS。

> 情感关系：避风港 → 补给港 → 远航港
>
> 产品设计：功能层 → 体验层 → 情感层

**为什么**："三"不是 AI 的发明，而是人类用了数千年的修辞技巧。"三原则"认为三个元素容易产生节奏感与完整感。AI 做的，是把这门手艺工业化：凑出三个名词，配上 Emoji、括号与箭头，普通列举就升级成了"底层模型"。至于三个维度是否同层、是否重叠，往往无人追究。

**数据**：据 Pangram 对其自有语料的统计，三段式结构在 AI 文本中的出现频率约为人类文本的四倍。

**识别方法**：把三层的名字互换、增删一层，论述是否依然成立？如果成立，说明分类只是凑数。

## 四、小事必须升华

**表现**：事实记录之后，紧跟一段"意义阐释"。

> 一次沟通中我用十分钟输出了方案。
>
> → 这不是"AI 很快"，而是"我的思维被放大了"。

**为什么**：人类写作常满足于记录事实，AI 则被训练成"不要让内容显得单薄"。于是：写完方案不是完成工作，而是跑通闭环；整理资料不是建立文件夹，而是沉淀知识资产。事实负责发生，感悟负责阻止它白白发生。

**识别方法**：删掉所有"这意味着""这不仅是……更是……"的段落，文章是否照样成立？如果是，这些升华就是后加的装饰层。

## 五、中文负责说事，英文与代码负责定调

**表现**：句子里夹入 `Agent Workflow`、`vector_store`、`memory_log` 之类的英文术语或代码块，替代本可以说清的中文表述。

> 我用 AI 做了一个简单的记账小程序。
>
> → 我第一次跑通了从需求定义、数据建模到 Agent Workflow 的完整闭环。

**为什么**：术语的本来作用是提高表达精度。但当作者无法用自己的话解释这个术语，也说不清这段代码证明了什么，术语就脱离了信息功能，转而为文本提供"技术质感"。代码能否运行并不重要，重要的是它出现在文章里。

**识别方法**：把每个术语替换成它的中文解释。如果换完之后句子含义不变、只是"没那么高级了"，术语就是气氛组。

## 六、Emoji 当路标用

**表现**：Emoji 不表达情绪，而是标注信息的类型。

- ✅ 接下来是一条正确的信息
- ⚠️ 接下来是一条必须注意的信息
- 💡 接下来是一条新信息或结论
- 🚀 文章即将起飞并进入升华
- 🙏 一段官话正在努力显得有人情味

**为什么**：据 Pangram 的语料统计，AI 更偏爱 ✅、⚠️、1️⃣、🚀 这类具备界面功能的符号，人类则更常使用笑脸 😃 和爱心 ❤️。也就是说：

> 人类用 Emoji 表达"我现在是什么感受"，
>
> AI 用 Emoji 提示"你现在应该注意哪里"。

它是一套视觉化的信息导航系统，而非情绪表达。

**识别方法**：统计一下 Emoji 的类型。如果全是功能性符号、且每段开头都挂一个，就是典型信号。

## 七、文章必须结束，意义不能结束

**表现**：结尾从具体事件一路推到人类文明。

> 💡回过头看，这段经历带给我的，远不只是效率上的提升……我们正在经历的，是一场关于工作方式、组织能力乃至人类认知边界的深刻重构。🚀

**为什么**：一篇"合格的"AI 文章不能停在"我以后还会用"。常见的升华路线是：

我节省了十分钟 → 我的工作方式改变 → 团队协作模式重构 → 组织能力迎来新范式 → 人类认知边界被再次打开。

从十分钟到全人类，中间不需要任何证据，只需要几个箭头。维基百科的 AI 写作观察将这一习惯概括为：**对意义、影响和宏大趋势的过度强调**——事情刚刚发生，就开始为它撰写历史地位。

**识别方法**：把结尾的宏大名词全部换成具体动作，如果短文瞬间缩水一半，那部分内容就是靠形容词撑起来的。

## 附：AI味快速自检清单

- [ ] 开头是否用"不是……而是……"制造了一个不存在的误解？
- [ ] 每个观点是否都编号、每段感悟是否都加粗？
- [ ] 是否存在删掉后信息毫无变化的表格或列表？
- [ ] 分类是否恰好三层，且每层下面都有箭头和括号？
- [ ] 是否每件小事后面都跟了一段意义阐释？
- [ ] 是否混入了无法被中文解释的英文术语或示例代码？
- [ ] Emoji 是否全是功能性符号而非情绪表达？
- [ ] 结尾是否出现了"范式""重构""认知边界"这类宏大名词？
- [ ] 把所有形式外壳（编号、表格、Emoji、术语、升华）剥掉后，还剩下几句具体内容？

最后一条最关键。原文作者做过一次类似的"消融实验"：把编号、加粗、表格、Emoji、代码块、英文术语、三段式、升华结尾逐一去掉，剩下的核心主张只有一句——真实经历加上结构化呈现，比纯生成更有价值。反过来，只保留形式、抽掉内容，文章就变成一张空货架：整齐、高级、有三列战略纵深，却不知道作者到底经历了什么。

## 如何减弱AI味

形式本身不是问题，**形式与信息量的比例**才是问题。可行的做法：

1. **用具体细节替换抽象升华**——时间、数字、对话、失败之处，比"深刻重构"更有说服力；
2. **允许颗粒度不匀**——人类写作有详有略，不会每段都是三行；
3. **表格只用在数据密集处**——一句话能说清的事就直说；
4. **术语要么解释，要么不用**；
5. **结尾可以平淡**——停在事情本身，不必停在人类文明。

判断标准始终是同一个：**这段话里的形式，是否在为内容服务。**
